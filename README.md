# לקט — דף מקורות לשולחן ערוך

כלי לימוד אישי שבונה "דף מקורות" מדויק לכל סימן בשולחן ערוך: מהטור והבית
יוסף — אל המקורות שהם מביאים (גמרא, רמב"ם, ראשונים, מדרש, תנ"ך) עם המפרשים
שלהם — ועד תמצית הלכה למעשה לפי סעיפי השו"ע. הדף ניתן להדפסה, לייצוא
ולאיסוף לקבצי לימוד.

**מקומי בלבד, משתמש יחיד** — אין התחברות, אין חשבונות, אין שרת מרוחק פעיל.
כל הנתונים נשמרים ב-SQLite אצלך במחשב.

## התחלה מהירה

דרישות:
- Node **18.20.1** בדיוק (ר' `.nvmrc`) — better-sqlite3 מותקן כבינארי שנבנה
  במיוחד עבור הגרסה הזו; גרסת Node אחרת תיכשל בפתיחת ה-DB.
- [Claude CLI](https://claude.com/claude-code) מחובר (`claude` בנתיב) — רק אם
  רוצים את ניתוח ה-AI לסעיפים; שאר האפליקציה עובדת בלעדיו.

```bash
nvm use            # קורא את .nvmrc
npm install
npm run local       # next dev -H 127.0.0.1 -p 3000, פותח על localhost:3000
```

הנתונים נשמרים ב-`data/annotations.db` (לא ב-git). מיגרציות סכמה רצות
אוטומטית בעלייה הראשונה של השרת; מיגרציה שמוחקת/משנה נתונים קיימים כותבת
גיבוי מלא ל-`data/backups/` לפני שהיא נוגעת בכלום.

## תהליך העבודה

```
בחירת סימן  →  לימוד (פאנלים / לפי סעיפים)
                ↓
סימון טקסט בב"י/טור  →  "הגדר מקור"  →  זיהוי + אישור נוסח + מפרשים  →  לדף
                ↓
הוספת הסבר / שאלה-תשובה / כותרת  ·  קישור לסעיף  ·  הסתרה מהדף הסופי
                ↓
✨ ניתוח סעיף (מהממשק, או דרך Claude Code)
                ↓
דף מקורות  →  PDF / Word / הדפסה  ·  קובץ לימוד  →  ייצוא מאוחד
```

## פיצ'רים

### מסך הלימוד — פאנלים ("כל המקורות")
טור, בית יוסף, שולחן ערוך והמפרשים של אותו חלק (למשל ט"ז ומגן אברהם באורח
חיים; ש"ך בשאר החלקים) — כל אחד בפאנל נפרד, לצד לצד, בלי לדפדף בין ספרים.

### תצוגה "לפי סעיפי שו״ע"
כל סעיף בשולחן ערוך הופך ליחידת קריאה אחת: טקסט הסעיף + כל הערות המפרשים
שבאמת שייכות אליו, לפי קישורי ספריא (`lib/sefaria.ts`, `buildSeifBlocks`) —
לא לפי ניחוש אינדקס. **מגבלה ידועה:** המיפוי תלוי בקישורים שספריא מספקת;
אם קישור אחד חסר, בלוק מסומן "⚠️ מיפוי לא ודאי" ואפשר לאמת/לדגום דרך
`npm run check-seif-mapping`. טור ובית יוסף לא מוצגים כאן אוטומטית (אין
מיפוי אמין לסעיף) — אפשר לקשר אותם ידנית מהדף (ראו למטה).

### משיכת מקור מתוך הטקסט
סימון טקסט בטור/בית יוסף מפעיל זיהוי אוטומטי (`lib/sourceDetection.ts`) —
מזהה ייעודי לקטע בודד (`detectSourceRef.ts`) עם נפילה לסורק טקסט מלא שיודע
לזהות גם ראשונים/אחרונים (`parser.ts`, לפי `AUTHOR_MAP`) — ואז בחירת נוסח
מדויק מספריא ומפרשים, לפני הוספה לדף. שני המזהים מכוסים בבדיקות רגרסיה
(`npm test`) נגד תיקוני זיהוי היסטוריים.

### דף מקורות
מקור / הסבר / שאלה-תשובה / כותרת / תמונה / מקור ידני — כל אחד ניתן לקישור
לסעיף שו״ע (לתצוגת "לפי סעיפים") ולהסתרה מהדף הסופי. ברירת המחדל: טקסט
הבסיס (שו״ע/טור/בית יוסף) מוסתר בדף הסופי, כל השאר מוצג.

### ייצוא והדפסה
PDF (Playwright), Word (`.docx`), טקסט פשוט, והדפסה ישירה מהדפדפן.

### קבצי לימוד
אוסף סימנים מכמה מקומות בשולחן ערוך, מיוצא כחוברת אחת. שני מצבי ארגון:
לפי נושא (`topic`) ובחירה חופשית (`free`).

### הגדרות תצוגה
גודל גופן, ריווח שורות וניקוד — נגישים דרך סמל ⚙ בראש דף הסימן.

### ניתוח AI לסעיף
המנגנון היחיד ל-AI באפליקציה: סיכום + נקודות הלכה למעשה לכל בלוק ("לפי
סעיפי שו״ע"), כל נקודה מעוגנת ומצטטת `source` מתוך רשימה סגורה של תוויות
המקורות שנשלחו למודל (מאומת בשרת). נשמר ומזהה "התיישנות" לפי hash של
התוכן — לא נמחק אף פעם, רק מסומן כלא-מעודכן עד שמרעננים.

## עבודה עם Claude Code

אין מפתח API בתשלום — ה-AI רץ דרך ה-`claude` CLI המקומי שלך
(`lib/claudeCli.ts`), גם מהממשק וגם מכאן:

| רוצה… | אומרים ל-Claude Code |
|---|---|
| להפעיל את האפליקציה | "תפעיל את לקט" |
| לנתח/לרענן סעיפים בסימן שלם (או כמה) | "תנתח את סימן א באו"ח" — ר' `.claude/skills/seif-analysis` |

**מגבלה ידועה:** ה-AI עובד רק כשהשרת רץ אצלך עם `claude` מחובר.

## ארכיטקטורה בקצרה

Next.js 14 (App Router, TypeScript) · SQLite מקומי (`better-sqlite3`,
`data/annotations.db`, סכמה ב-`lib/db.ts`) · טקסטים ומטמון מספריא
(`lib/sefaria.ts`, `cache/sefaria/`) · `claude` CLI לניתוח AI.

## פיתוח

```bash
npm test                    # vitest — golden set לזיהוי מקורות
npm run check-seif-mapping  # דגימה חיה על 20 סימנים, מדווח מיפויים לא ודאים
npx tsc --noEmit
npm run build
```

הוספת מפרש חדש לתצוגת "לפי סעיפים": שורה אחת ב-`COLLECTIVE_TITLE_TO_SOURCE_KEY`
(`lib/sefaria.ts`) + הוספת ה-fetch שלו ל-`/api/siman-texts`. הוספת סוג מקור
חדש לזיהוי: `lib/authorMap.ts` / `lib/rambamMap.ts` / `lib/tanakhBooks.ts`
לפי הסוג, ואז מקרה בדיקה ב-`lib/parser.test.ts` או `lib/detectSourceRef.test.ts`.

## מה בכוונה לא כאן

- **ריבוי משתמשים, קבוצות, ניהול/מודרציה** — הוסרו מ-main; הקוד שמור בענף
  `archive/multi-user` אם שיתוף יחזור להיות רלוונטי.
- **נתיב API בתשלום (Anthropic SDK) וסוכנים מותאמים אישית** — הוסרו; ניתוח
  הסעיף (למעלה) הוא מנגנון ה-AI היחיד שנשאר.
- **Deploy לשרת** (`halacha.lazari.site`) — לא פעיל כרגע (השרת לא עונה),
  נשאר לעתיד; הסקיל `deploy-halacha` קיים מקומית אצל המפתח, לא בריפו הזה.
- **`halachic-extractor`** (הפרויקט הישן ב-Python/FastAPI) — בארכיון,
  הוחלף במלואו על ידי לקט.
